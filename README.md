# 📊 Exploratory Data Analysis on Netflix Movies & TV Shows

This project performs an in-depth **Exploratory Data Analysis (EDA)** on the Netflix Movies and TV Shows dataset to uncover insights about content trends, production patterns, and platform growth over time.

The analysis focuses on **data cleaning, feature engineering, statistical exploration, and visual storytelling** using Python’s data analysis libraries.

---

## 🎯 Project Objectives

The primary goals of this project are:

- Understand the structure and quality of the Netflix dataset
- Perform comprehensive **data cleaning and preprocessing**
- Handle missing values and inconsistent data formats
- Extract meaningful insights using **EDA techniques**
- Visualize trends in Netflix content using effective data visualization
- Explore patterns related to:
  - Content types
  - Release trends
  - Country-wise production
  - Genre distribution
  - Duration of movies and TV shows

---

## 🗂 Dataset Information

The dataset contains information about Netflix titles including:

- Title
- Content Type (Movie / TV Show)
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre (Listed In)
- Description

This dataset allows analysis of **content distribution and platform growth patterns**.

## 🔧 Data Cleaning & Preprocessing

The following steps were performed:

- Handling missing values
- Parsing and converting date formats
- Extracting useful features from columns
- Standardizing categorical data
- Splitting multi-value columns (genres, countries)
- Removing duplicates and inconsistent entries

## 📊 Exploratory Data Analysis

The project explores several analytical questions such as:

- How has Netflix content grown over the years?
- What is the ratio of **Movies vs TV Shows**?
- Which countries produce the most Netflix content?
- What are the most common **genres**?
- What are the most frequent **content ratings**?
- What trends exist in **content duration**?
- How has Netflix expanded its library over time?

## 📈 Visualizations Used

Different visualization techniques were used to analyze patterns:

- Bar Charts
- Count Plots
- Line Plots
- Distribution Plots
- Heatmaps
- Pie Charts

These visualizations help understand **content trends, growth patterns, and distribution insights**.

---

## 🔍 Key Insights

Some important observations from the analysis include:

- Movies dominate the Netflix catalog compared to TV Shows.
- The United States contributes the largest share of Netflix content.
- Netflix experienced significant growth in content additions after 2015.
- Certain genres such as **Dramas, Comedies, and Documentaries** appear most frequently.
- Content ratings show Netflix targets a wide range of audiences.
